# Face Detection Using Python and OpenCV

## Project Overview
This project is a real-time Face Detection system developed using Python and OpenCV.  
The system detects human faces from a webcam video stream using the Haar Cascade Classifier and draws bounding boxes around detected faces.

---

## Features
- Real-time face detection using webcam
- Detects multiple faces
- Uses Haar Cascade pretrained model
- Draws rectangles around faces
- Beginner-friendly project

---

## Technologies Used
- Python
- OpenCV
- Haar Cascade Classifier
